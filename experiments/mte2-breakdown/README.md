## 3. 核心瓶颈 TOP5

- 本轮有效PMU继续支持GM→L1供数通路耗时占主导；**没有获得HBM服务、L2查询、ND→NZ执行各自的独立等待周期**。活动时间、请求量和总耗时差额不足以产生三个可相加的时间。
- `MemoryDetail`首次在模型仍占卡时返回207001内存分配失败；排除这些采样的插桩字段。释放模型后四组未出现该错误，但只有block 2/5/8/11/14/17/20有非零`aic_mte2_active_bw`，其余16核为零。PMU却显示全部23核有大量MTE2活动和搬运字节。记录为覆盖或映射异常，未证明根因；不将零字段纳入平均或当作空闲。
- 编译版Insight后端成功导入有效ND升维`visualize_data.bin`，`source/details/baseInfo`和`source/details/memoryGraph`返回结构化数据。core0的L2请求123571、hit354，与CSV核对；`source/api/instructions/dynamic`返回空数组。这次MemoryDetail没有提供可用的设备指令时序。

## 4. 优化建议 TOP5

下一步证据目标是取得有效的逐核DMA/等待周期，或在保持同一搬运指令和分块的前提下控制数据来源；未达成前，不把HBM带宽打满、L2堵塞或格式转换主导中的任何一个写为确定根因。本轮未部署NZ、未修改BF16或原生内核、没有新增模型加速成绩。
